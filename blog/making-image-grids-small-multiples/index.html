Getting Griddy: How to Make Image Grids (or Small Multiples)

November 5, 2022

Small multiples—essentially a grid of maps, visualizations, or photos—are a great way to present information. Data visualization arranged in this way helps readers spot trends or patterns, relate multiple variables, and see numerous conditions at once. And unlike an animation of the same data, small multiples make it easy to quickly compare any individual component visualizations without interactively scrubbing through a timeline.

Small multiples display of soil moisture conditions in Germany arranged by month and year.
Credit: NASA Earth Observatory.

Small multiples are incredibly intuitive and easy to read. Making them however remains a challenge in many tools. Despite how common the technique is, direct support for producing small multiples is not currently a core feature in many GIS applications.

That is a limitation we can circumvent. I am going to show you two ways to produce an image grid, first in Photoshop and then in the command line. Both techniques have their pros and cons, and both are broadly applicable to any type of images whether they be maps, charts, or photographs.

All you need to get started is a bunch of images. How you create or obtain them is up to you. We will focus only on putting them into a grid quickly and easily.

Use the menu below to choose which technique you’d like to learn.

  • Photoshop
  • Command Line

Adobe Photoshop

Did you know Photoshop can create in image grid with just a few clicks? Photographers have been using this feature for years to create contact sheets.

In fact, that is exactly what the tool is called. Let’s see how it works:

  1. Open Photoshop.
  2. Navigate to the File menu, then Automate, and select Contact Sheet II.

The Contact Sheet feature in Photoshop is one of the software's best kept not-so-secrets.

  1. Import the images you want to use in the grid. In the Contact Sheet II options you can select whether to use a specific folder containing your images, individually select multiple files, or use the images that are already open in Photoshop.

Options abound for contact sheets.

I find it best to have all my individual images in their own folder, and then use this folder as input for the Contact Sheet tool.

  1. Setup the layout of the grid (small multiples) to be created.

    • Contact Sheet II will automatically resize your images to fit the document size you specify. In some cases, this is great and you can choose the desired output size and let it do all the work.

    • If you do not want your original images resized—perhaps if they include text or other features you want to retain in full detail—you will need to do a little math. It is easy to figure out your final output dimensions and decide how many rows and columns this will require. For instance, if you have 30 images that are 500x500 pixels each, you might decide to have 5 columns and 6 rows. This means your document width will be 2500 pixels and the document height will need to be 3000 pixels.

    • If you want to be able to change the background color or do not wish to have a white background, be sure to uncheck the option to flatten all layers. This will leave each image on its own layer, allowing you to change the color and style of the background layer.

  2. Click OK and watch the magic happen!

Command Line (ImageMagick)

ImageMagick is a staple of open source image manipulation. It can edit, combine, annotate, and transform all sorts of image filetypes in powerful ways.

It is no surprise then to see that ImageMagick makes it rather painless to create small multiples or grids.

ImageMagick must first be installed on your system for this to work. Before continuing, ensure this is the case or install ImageMagick if necessary. If on a Mac, I recommend using Homebrew to do so.

Like many command line applications, ImageMagick is not a single program but a collection of many separate commands. Among these is the montage command.

Montage was originally designed to make a table of thumbnail images or proof sheets. That is pretty convenient since that is essentially what small multiples are.

Let’s put it to work.

  1. Begin by ensuring all of your images are together in a single folder with no other files.

  2. Determine how you want your grid to look. How many rows? How many columns? Should there be any gaps between the individual images? What color should the background be?
