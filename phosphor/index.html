    ArcGIS Pro style (.stylx)

    A continuous ramp made of 17 colors joined by CIELAB segments, so lightness stays linear in ArcGIS Pro. To use it in Pro, open Catalog → Styles, right-click and choose Add → Add Style, then pick this file. The ramp then appears in the Symbology pane's color scheme list (turn on Show names and Show all).

    QGIS style (.xml)

    A gradient color ramp with 33 stops. In QGIS, open Settings → Style Manager, choose Import/Export → Import Item(s), pick this file, select the ramp and click Import. It then appears in every color ramp menu.

    GDAL color relief (.txt)

    One row per step (value, R, G, B, A), with data values spaced evenly from min to max. No-data pixels (nv) get the min color. Use it with gdaldem color-relief input.tif ramp.txt output.tif -alpha. GDAL blends between rows; add -exact_color_entry or -nearest_color_entry for classed colors.
