    ArcGIS Pro style (.stylx)

    A continuous ramp made of 16 colors joined by CIELAB segments, so L* stays linear in ArcGIS Pro. To use it in Pro, open Catalog → Styles, right-click and choose Add → Add Style, then pick this file. The ramp then appears in the Symbology pane's color scheme list (turn on Show names and Show all).

    QGIS style (.xml)

    A gradient color ramp with 32 stops. In QGIS, open Settings → Style Manager, choose Import/Export → Import Item(s), pick this file, select the ramp and click Import. It then appears in every color ramp menu.

    Settings are saved in the URL, so you can bookmark or share a gradient.
